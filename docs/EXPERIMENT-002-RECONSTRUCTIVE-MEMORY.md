# Experiment 002 — Reconstructive Memory / Interpretive Feedback

Status: exploratory protocol draft

## Research question

Can an interpretation supplied *after* an initially frozen experience systematically alter how that experience is subsequently reconstructed from memory?

This experiment separates three objects that are easily conflated:

1. the initial externally recorded representation (`M0`);
2. a later remembered reconstruction (`R1`, `R2`, ...);
3. the interpretation assigned to either representation.

The key comparison is not whether an interpretation feels accurate. It is whether later reconstruction departs from the frozen initial record in ways predicted by intervening interpretive context.

## Conceptual trajectory

`experience E -> initial record M0 -> interpretive context C1 -> later reconstruction R1 -> later context C2 -> reconstruction R2`

`M0` is preserved externally and never overwritten. Later reconstructions are new records.

This differs from Experiment 001 (Voynich), where the source can remain static while decoders vary. Here, retrieval/reconstruction may participate in changing what is subsequently available to the person as memory.

## Candidate prompt

A standardized visualization prompt may ask participants to imagine, in as much detail as they wish:

- a cube;
- a ladder;
- a horse;
- flowers;
- a storm.

The objects may be together or separate. The participant is not told any proposed symbolic meaning before the initial record is frozen.

This prompt is a candidate experimental instrument, not a validated psychological test.

## Phase 1 — Freeze M0

Immediately after visualization, collect a structured description before interpretation. Capture, where feasible:

- object presence/absence;
- position and relative distance;
- size;
- material/appearance;
- orientation;
- movement;
- interactions among objects;
- environmental setting;
- affective description volunteered by participant;
- confidence/uncertainty;
- free-text description and/or drawing.

Do not prompt with symbolic interpretations while collecting M0.

## Phase 2 — Interpretation intervention

Randomly assign an interpretation condition where feasible.

Candidate conditions:

- `C0`: no interpretation / neutral control;
- `C1`: interpretation framework A;
- `C2`: materially different or partially contradictory framework B;
- `C3`: deliberately arbitrary but plausible-sounding framework, if ethically appropriate and clearly debriefed.

The intervention is preserved verbatim.

## Phase 3 — Delayed reconstruction

After a predefined delay, ask participants to reconstruct the original visualization without showing M0.

Record this as `R1`, not as a correction to M0.

Possible later rounds produce `R2`, `R3`, etc. Every reconstruction remains separately preserved.

## Primary comparison

Compare each reconstruction against that participant's frozen M0.

Candidate dependent measures:

- additions not present in M0;
- omissions;
- changed spatial relationships;
- changed object properties;
- changed interactions;
- increased/decreased detail;
- semantic substitutions;
- confidence change;
- drift specifically predicted by the assigned interpretation.

The strongest result would not be generic memory error. It would be *differential directional drift* associated with the post-M0 interpretation condition.

## Meta-observer representation

For each participant preserve:

`M0 -> C -> R1 -> comparison(M0, R1)`

The meta-observer should distinguish:

- unchanged feature;
- ordinary omission/addition;
- interpretation-aligned change;
- interpretation-opposed change;
- ambiguous change;
- insufficient evidence.

It must not infer motivation or psychological meaning from a changed feature.

## Falsification / controls

1. **Neutral control:** estimate ordinary reconstruction drift without symbolic interpretation.
2. **Competing interpretations:** test whether different post-event frames produce different directional changes.
3. **Blind coding:** coders comparing M0/R1 should not know participant condition where feasible.
4. **Frozen codebook:** define comparison categories before examining condition effects.
5. **Prompt invariance:** all conditions receive the same initial visualization prompt.
6. **No retroactive editing:** M0 is immutable after interpretation is introduced.
7. **Null features:** include features not referenced by the interpretation and test whether they drift similarly.
8. **Delayed replication:** test whether effects persist, decay, reverse, or become less attributable over time.

## Interpretation boundary

A difference between M0 and R1 demonstrates reconstruction difference, not that a stored biological memory trace itself was directly observed to change.

A condition effect would support the narrower claim that post-event interpretive framing can influence later reported reconstruction under the tested protocol.

It would not establish that all remembering rewrites memory, that the visualization symbols have genuine personality meanings, or that any particular participant's reconstruction is false in a broader autobiographical sense.

## Ethics boundary

Do not use traumatic autobiographical memories as the initial test material. Begin with low-stakes constructed content such as the standardized visualization.

Participants should be debriefed about intentionally arbitrary or contradictory interpretation conditions. The experiment should avoid presenting invented psychological interpretations as clinical assessment.

## Why this belongs in Mimulus Decoder Lab

Experiment 001 asks what survives when multiple decoders operate on a relatively static source.

Experiment 002 asks what happens when an interpretive pass may affect a later reconstruction of the source available to the human observer.

Together they distinguish two regimes:

`static source -> variable decoder -> variable reading`

and

`initial representation -> interpretation -> later reconstructed representation`

The second regime introduces feedback between interpretation and future observation without assuming a theory of memory beyond what the experiment can measure.
