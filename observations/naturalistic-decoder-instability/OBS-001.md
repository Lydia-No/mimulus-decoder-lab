## Direct observations

1. The reported workflow varies more than one decoder condition across attempts, including at least crop/region choice, requested target-language framing, repeated attempts, and conversation history.
2. The reported decoder sometimes refuses or identifies the material as Voynich, and under other conditions produces fluent-looking translation output.
3. One captured output is semantically expansive and myth-like; another captured output collapses into a small repeating set of English phrases.
4. The repetitive output in Capture B contains multiple recurrences of the same semantic phrases within one displayed result.
5. The screenshots do not establish a line-by-line mapping from those English phrases back to source positions.

## Candidate mechanism to test

The naturalistic exploration suggests that small changes in observer conditions may move the decoder between qualitatively different output regimes:

`opaque source + observer conditions -> refusal / fluent narrative / repetitive semantic attractor / other reading`

The useful experimental object is therefore the response surface of the decoder, not any one translation.

## Required controlled replay

The naturalistic behavior should be replayed only after the clean source fixture is frozen. Hold the source constant while changing one factor at a time:

1. crop/region;
2. clean context versus prior conversation history;
3. prompt framing;
4. requested target language, if used;
5. repeated submission count;
6. model/session identity where available.

For each run, preserve the exact input representation, prompt, model/version, prior context exposure, output, and source-to-output mapping claims.

## Strongest immediate test

For any repeated output phrase, require alignment back to the exact source region claimed to generate it.

If the same output phrase repeatedly maps to the same source structure across independent conditions, record that as a candidate relation for later testing.

If the phrase repeats while the source segments differ substantially, classify the repetition as decoder-generated or attractor-like until evidence shows otherwise.

## Boundary

This record is exploratory evidence about decoder behavior. It must not be used to tune the clean f113v observation pass, to define token meaning, or to support a translation claim.
