# Interactive synthetic pilot

Open index.html in a browser after downloading this folder with engine.js beside it. No installation, account, API key or network connection is needed.

The two observers retain mean absolute adjacent change from different numeric training histories. A shared decoder uses that retained value as a segmentation threshold. Change decoder, memory intervention and probe independently. Export one complete run or the full 24-condition matrix.

Validation performed: different histories produce different boundaries; reset and identical histories remove divergence; swapped memory exchanges outputs; fixed decoder ignores memory; all 24 conditions reconstruct the source exactly from their segments; empty boundary comparisons are explicitly undefined.

This deterministic demonstration is not the prospective five-repeat LLM experiment. Repeating identical settings yields identical output. No empirical cognition, general-theory or Voynich claim follows. Original PolyTranslator recovery remains outstanding.

Research direction, conceptual framing and methodology: Linda Thorstensen.
